- **Location:** `scripts/oracle-replay-batch.js:41-51` (thread `PRRT_kwDOO-7Gas6lEv8S`)

- **CR's claim:** `catch (_)` swallows every error from `getBlockHeaderByNumber(ORPHAN_HEIGHT)`, including RPC timeouts and rate limits. In the incident state (`before.height == 967143`) a transient failure sets `held143 = null`. - **Verification (walked):**
  1. The incident state is `height 967143 / nextBlockIndex 0 / tip = orphan`, the only state the script submits from (`:54`). Since `967143 >= ORPHAN_HEIGHT`, the guarded block at `:41` is entered.
  2. `LibDoefinBlockHeaderOracle.getBlockHeaderByNumber` reverts `ValueOutOfRange` only when `blockNumber > currentHeight || blockNumber <= currentHeight - 17` (`contracts/libraries/LibDoefinBlockHeaderOracle.sol:68`). For `blockNumber == currentHeight == 967143` (offset 0), neither holds. **In the incident state the call cannot revert on-chain**, so the `catch` can only ever catch transport or provider errors. Its comment (`/* 967143 already out of the 17-slot window */`) is never true there.
  3. `held143 === null` makes `:48` true. The script logs "Oracle already holds the canonical chain (height 967143) — nothing to replay." and returns `{ recovered: true }`, and `main()` exits 0 (`:126`). It never calls `estimateGas` and never sends a transaction.
  4. **Reproduced** without a network or the hardhat runtime (snippet below). The unmodified script ran against a stub oracle in the incident state whose `getBlockHeaderByNumber` throws `HH110: 504 Gateway Time-out`.
     - Unmodified: returned `recovered: true`, with 0 `estimateGas` calls, 0 `submitBatchBlocks` calls and the misleading log line.
     - Patched (below): throws, so `main()` exits 1. The healthy dry-run path is unchanged.
     - Boundaries: at `h = 967159` the patched script still reads 967143 (in window); at `h = 967160` it skips the read (out of window).
  5. **Boundary proof for CR's condition:** 967143 is out of the window ⇔ `967143 <= H - 17` ⇔ `H >= 967160 = ORPHAN_HEIGHT + RING`. This is exactly the library's revert condition, and `RING` is already imported (`:28`).
     - The eviction branch is also semantically safe. No PoW-valid child of the orphan exists (see the SEC-015 impact), so the height can only pass 967143 if the orphan was replaced. `H >= 967160` therefore implies the oracle has recovered.
  6. **Blast radius:**
     - The fork rehearsal would catch this: `scripts/upgrades/rehearse-scrum521-fork.js:101` asserts `replay.after.height === HELD_BATCH_TIP`.
     - The standalone `npm run oracle:replay:base` has no such backstop, and it is step 2 of the production runbook.
     - Hardhat's HTTP provider retries only HTTP 429 (`node_modules/hardhat/internal/core/providers/http.js`: 6 retries, Retry-After ≤ 5 s). Timeouts, 5xx responses and connection resets surface as thrown errors.
- **Grounding:** this is the SEC-015 (HIGH) recovery path: PR body "Deployment runbook" step 2, and `doefin-backend/docs/smart-contract-task-oracle-reorg-index-underflow.md` §Rollout (A).2. No `invariants.md` entry covers the oracle.

  - **Medium** (promoted from the Low default) on a walked and reproduced path. It matches the rubric line "correctness gap in tests/scripts that hides regressions".
