### CR-4319907478 · ACCEPT-FIX · Medium

- **Location:** `contracts/audit/DoefinInvariantHarness.sol:1286-1295` (`_registryCanonical`), property `:1269-1273` (thread `PRRT_kwDOO-7Gas6uJHRd`)
- **Category:** `tests` (fuzz harness; test-only)

- **CR's claim:** `_registryCanonical` checks only `partitions[i] == 1 << i` and the parent. It never checks that a market covers every outcome, so shape `k == 4` (partial `[1, 2]` on `triConditionId`, the exact CTF-001 registration) passes on pre-fix code, and no other property catches it. It also skips INV-CTF-2's position-ID and reverse-mapping clauses. CR guesses the negative control "probably failed only on the reordered shapes (`k == 1`, `k == 3`)".
- **Verification — which `_shape()` indices the property can catch on the pre-fix contracts (`3c78b6f`):**

  Pre-fix registry semantics (`git show 3c78b6f:contracts/libraries/LibPositionRegistry.sol:103-158`):
  - Every `splitPosition` calls `registerPositionPairs`.
  - The first write per `(condition, parent, collateral)` wins.
  - A later split whose positions or partitions differ reverts `InvalidMatch`, and with it the whole split.
  - A position already mapped to another market also reverts.

  The harness seeds the binary `conditionId` in its constructor. `triConditionId` is not seeded. A quarter of `rawAmount` values give amount 0, and a 0-amount partial split burns 0 of the union position, so it is free.

  | `_shape` k | condition | partition | class | pre-fix effect at the root | property as committed | after the fix |
  |---|---|---|---|---|---|---|
  | 0 | binary | `[1, 2]` | canonical | same as the seed: no new entry | — | — |
  | 1 | binary | `[2, 1]` | reordered | **reverts `InvalidMatch`** (seed registered), so it can never register | — (unreachable) | — |
  | 2 | tri | `[1, 2, 4]` | canonical | registers if it is the first root split of tri | holds | holds |
  | 3 | tri | `[4, 2, 1]` | reordered (CTF-002a) | registers if first | **caught** (4 ≠ 1) | caught |
  | 4 | tri | `[1, 2]` | **partial — the CTF-001 registration** | registers if first (amount 0 is free) | **not caught** (ascending singletons) | caught (length 2 ≠ 3) |
  | 5 | tri | `[3, 4]` | grouped, full | registers if first | caught (3 ≠ 1) | caught |
  | 6 | tri | `[1, 6]` | grouped, full | registers if first | caught (6 ≠ 2) | caught |
  | 7 | tri | `[2, 4]` | partial | registers if first (amount 0) | caught, by **ordering** (2 ≠ 1), not by completeness | caught |
  | any, `nested = true` | binary or tri under `coll(conditionId, 1)` | any | nested (CTF-002c) | registers (new market key) | caught (parent ≠ 0) | caught |
